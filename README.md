# DocuMind Enterprise AI

An enterprise-grade RAG (Retrieval-Augmented Generation) system that allows users to upload PDF documents and ask questions in natural language.

## Features
- PDF Upload
- Document Parsing
- Semantic Search
- Pinecone Vector Database
- OpenAI Embeddings
- Citation-Based Answers
- FastAPI Backend

## Tech Stack
- Python
- FastAPI
- LangChain
- Pinecone
- OpenAI
- Uvicorn

## Workflow
PDF → Chunking → Embeddings → Pinecone → Retrieval → LLM Response
